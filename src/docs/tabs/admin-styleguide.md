ADMIN STYLEGUIDE (TKMMDI)

Detta dokument styr allt som rör design, layout och komponenter i adminpanelen. Bolt ska alltid läsa och följa denna guide innan ändringar görs.

🎨 FÄRGER
Element	Färg
Adminpanelens bakgrund	#f6f2e0
Kort / paneler	#a1c798
Textfält bakgrund	#ffffff
Primär knapp	#000000 (svart)
Sekundär knapp	#56c5c5
Underflikar (ej aktiv)	#f6f2e0
Aktiv underflik	#a1c798
Huvudflikar	svart
🧱 LAYOUT
Sidopanel (vänster)

Topprubrik: Adminpanel

Huvudflikar ligger direkt under rubriken

Vid klick på en huvudflik:

dess underflikar expanderar nedanför

alla andra huvudflikar kollapsar

Huvudflikars bakgrund är svart

Underflikar är #f6f2e0

Aktiv underflik markeras med #a1c798

Huvudytan (höger)

Bakgrund: #f6f2e0

Varje sektion ska ligga i ett kort:

bakgrund #a1c798

rundade hörn

lätt skugga

luftiga marginaler

🧩 KORT / CARDS

Alla kort ska:

ha rundade hörn (8–12px)

ha drop-shadow (svag)

använda #a1c798 som bakgrund

ha gott om padding

🔤 TYPOGRAFI
Rubriker:

Typsnitt: Lobster

Vikt: Bold

Färg: svart

Storlek: stor och tydlig (Bolt ska hålla konsekvens)

Brödtext:

Systemfont

Färg: svart eller mörkgrå

🔘 KNAPPAR
Primära knappar

Svart bakgrund

Vit text

Rundade hörn

Sekundära knappar

Bakgrund: #56c5c5

Vit text

📄 FORMULÄR

Inmatningsfält är vita

Rundade hörn

Tunn kant (ljusgrå)

Fyll ut hela radens bredd där det passar UX-mässigt

📊 TABELLER

Använd #f6f2e0 som radbakgrund

Alternativa rader kan ha mycket svag toning

Header-rad tydligt markerad

Text vänsterjusterad

Avstånd mellan rader ska vara generöst

🧭 NAVIGATION & INTERAKTION

All navigering sker från vänster sidopanel

Huvudflikar expanderar/kolapsar endast ett block åt gången

Breadcrumbs kan användas vid behov

Kort i dashboard kan vara klickbara
