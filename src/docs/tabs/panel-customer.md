# Kundpanelen – Specifikation

## 🧭 Flikar
1. Mina beställningar
2. Favoriter
3. Prenumerationer
4. Meddelanden
5. Inställningar

## 🛍 Mina beställningar
- Historik + status (under tillagning, redo, utkörd, slutförd)
- Möjlighet att betygsätta maträtter
- Visa kvitto / ladda ned PDF

## 💖 Favoriter
- Lista sparade rätter / kockar
- Länk till “Köp/Boka” direkt

## 🔁 Prenumerationer
- Lista aktiva prenumerationer
- Möjlighet att ändra datum, antal portioner
- Avsluta prenumeration

## 💬 Meddelanden
- Chatta med kockar (text, bild)
- Systemmeddelanden (leverans, uppdateringar)

## ⚙️ Inställningar
- Adress, betalmetod, språk, notiser

## 🎨 Design
- Färgtema: vitt, #f6f2e0, svarta knappar, orange detaljer
